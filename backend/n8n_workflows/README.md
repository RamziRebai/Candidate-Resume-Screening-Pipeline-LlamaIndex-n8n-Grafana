# n8n Workflow Reports Archive

This folder stores generated monitoring report snapshots emitted during workflow runs.

## Contents

- Multiple files named like `enhanced_workflow_report_YYYYMMDD_HHMMSS.json`
- Each file contains execution telemetry, confidence analytics, feedback stats, and runtime configuration details

## Source

Reports are generated by workflow monitoring logic (see `workflow/monitoring.py`) and saved as local artifacts before/alongside n8n delivery.

## Recommended Usage

- Keep for debugging and historical analysis
- Use for regression tracking across model/config changes
- Periodically archive or purge old files to reduce repository noise

## Git Hygiene

If this folder grows quickly in local development, consider keeping only representative samples in version control.
